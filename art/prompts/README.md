# 画像生成（Codex CLI）指示書

素案・紙芝居・キービジュアル・カットインを、Codex CLI の画像生成機能で作る。
ゲーム内のユニット・タワー・壁は **ここで作った三面図を下絵に Blender でモデル化** する（`art/blender/`）。

## 実行のしかた（くにさんのPCで）
```powershell
cd <IceSpearTD のクローン先>
git switch reborn
codex "art/prompts/README.md を読んで、未生成の画像を順番に作って art/concept/ に保存して"
```
1枚ずつ確認したい場合：
```powershell
codex "art/prompts/02-fumiya.md の指示どおりに画像を作って"
```

## Codex への共通ルール
1. 各プロンプトファイルの「出力」に書かれたパスと名前で保存する（PNG）。
2. 1ファイルに複数枚ある場合は、すべて作る（省略しない）。
3. 生成に使った最終プロンプトを、画像と同じ名前の `.txt` で横に保存する（再生成できるように）。
4. 実在の作品・キャラクター・作家の名前や画風名をプロンプトに入れない。ロゴや文字は画像に入れない（文字はゲーム側で載せる）。
5. 作り終えたら `art/concept/INDEX.md` に「ファイル名 / 内容 / 使ったプロンプトファイル」の表を追記する。
6. 画像生成が使えない場合は、プロンプトを `art/concept/_pending/<名前>.txt` に書き出して止まる（くにさんが ChatGPT に貼る）。
