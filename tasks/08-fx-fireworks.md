# 08 演出：パーティクル・手応え・花火

GDD §7（花火の全部）、§9.2（手応えの表の全行）、§9.3（パーティクル11種全部）

## 作るもの
- `src/game/fx/FxDirector.ts`：毎フレーム `world.events.drain()` の結果を受け取り、イベント → 演出（パーティクル・効果音・ヒットストップ・揺れ・数字・花火）に振り分ける **唯一の場所**。対応表はデータ（`src/game/fx/fxTable.ts`）にする。
- パーティクル（§9.3 の11種：frost_puff, ice_shard, crystal_spark, steam, ember_spark, smoke, poison_mist, shockwave, firework_*, snowfall, confetti）
  - `src/game/fx/ParticlePool.ts`：種類ごとのエミッターをプールで使い回す。同時発生数の上限を設定（低/中/高）で切り替え。
  - テクスチャは当面コードで生成（小さな円・ひし形・結晶形・煙のぼかし）。素材が届いたら manifest の `fx_<name>` で差し替え（タスク06と同じ契約）。
- 手応え（§9.2 の6行全部）：ヒットストップ（`FixedStepper.addHitstop`）、画面揺れ（強さ設定 切/弱/標準）、ダメージ数字（弾んでフェード。反応ダメージは大きく色付き）、被弾の白フラッシュ、建設の手応え、最後の1体のスローモーション。
- 花火：
  - `src/game/fx/Fireworks.ts`：§7.4 の7種（kiku, botan, yae, kamuro, senrin, niagara, snow）。打ち上げ（尾を引いて上昇）→ 開花 → 余韻（重力・減衰・ちらつき）。色はパレット（氷色系＋熱色系）。
  - 戦闘中（§7.1）：通常撃破の火花、同時3体以上・反応での撃破で小玉、誘爆の連鎖で色と大きさが段階的に上がる（chainDepth 8 で八重芯）、ボス撃破で尺玉。同時数の上限を超えたら古いものから消す。
  - 花火大会（§7.2）：`wave_clear` のスコア → 格（線香花火〜尺玉の5段階）ごとの演目（打ち上げの順番・数・種類）をデータ化（`src/game/fx/fireworkShows.ts`）。3〜6秒。
  - 鑑賞モード（§7.3）：`FireworksScene`。UI なし、背景は夜空と雪、BGM 切り替え。クリックで終了。演目の記録（`stage`, `grade`, `seed`）から同じ花火を再現できる。
- 背景の環境演出：雪が降る（snowfall）、夜空の星のまたたき。

## 受け入れ条件
1. 戦闘中に全イベント種類が何らかの演出につながっている（fxTable のテストで、events.ts の全 type を網羅していることを検査）。
2. 誘爆8連鎖で花火の段階が見て分かる。
3. 1000体同時撃破のストレステスト（デバッグコマンド）で 30fps を下回らない（パーティクル上限が効く）。
4. 花火大会の5段階が見て分かる。鑑賞モードで同じ記録から同じ花火が出る。
5. 設定で揺れ・パーティクル量を変えると即反映。
