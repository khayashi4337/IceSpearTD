# 13 タイトル・物語・進行・保存・ステージ2〜5

GDD §2（物語の全部）、§3.7、§5.6、§9.6（画面10種の全部）、§9.7、§8.2（ボス表の全部）

## 作るもの
- 画面（§9.6 の10種のうち、まだ無いもの全部）：
  1. TitleScene（キービジュアル `kv_title`、雪の背景、はじめる / 続きから / 花火鑑賞 / 図鑑 / 設定）
  2. StoryScene（紙芝居）：`src/data/story/stage<N>_{pre,post}.ts` の台本（コマ画像ID、話者、本文）を再生。クリック送り・オート・スキップ・ログ。画像は `story_s<N>_<pre|post>_<nn>`（素材が無い間は背景色＋場面名）。
  3. MapScene（大陸地図。5ステージの位置、星評価、熱の侵食レベル、解放状態）
  4. LoadoutScene（編成：タワー枠・護符枠・術札枠。ステージごとの枠数は §5.6）
  5. ResultScene（星評価、花火の格、獲得した護符・術札、図鑑の新発見）
  6. CodexScene（図鑑：タワー・敵・反応・札。発見済みのみ。反応は条件の説明つき）
  7. SettingsScene（音量3本、演出の長さ、画面揺れ、パーティクル量）
- 台本：§2.3 の5ステージ × 前後の紙芝居（各4〜8コマ）を、§2.2 の人物で書く。文体は高校生が読んで自然な日本語。分岐（ステージ5の前に A/B の選択）とエンディング2種（§2.3）。
- ステージ2〜5のデータ（§2.3 の地形の特徴を全部反映）：マップ、10ウェーブ、中ボス・ボス（§8.2 の表の全部）。ボスの技は events.ts に `boss_skill` の種類として追加。
- 進行：解放（§2.3 の「解放」列）、星評価（§3.7）、熱の侵食レベル（周回）、巻き戻し（ステージ中2回）。
- 保存（§9.7）：`src/save/Save.ts`（localStorage、すべて try/catch、バージョン付きで移行可能）。
- 術札（能動スキル）の使用 UI：HUD に2〜3枠、クールダウン表示、範囲の狙いをマウスで。

## 受け入れ条件
1. タイトルからエンディング（A/B 両方）まで通しで遊べる。
2. 保存してブラウザを再読み込みすると続きから遊べる。localStorage が使えない環境（プライベートウィンドウ相当。テストでは例外を投げる偽物）でも落ちない。
3. ステージ2〜5のボス技がすべて動く。
4. タスク12のシミュレーションを全ステージで回し、§10.3 の基準を満たすよう数値を調整する。
