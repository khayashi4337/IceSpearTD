# 05 戦闘画面に World をつなぐ

GDD §3.3, §9.1, §9.6（戦闘）、§11.2

## 作るもの
- `src/game/scenes/BattleScene.ts` を本実装に置き換える（今は M0 の仮）。
  - World を固定ステップで進める（`FixedStepper`。倍速・一時停止）。
  - 描画は World を読むだけ。エンティティ ID → Phaser オブジェクトの対応表で、出現・消滅・移動を同期。
  - 深度ソート：`isoDepth(x, y, layer)`（タイル → 壁/タワー/敵の順。敵は連続座標で）。
  - 敵：位置、移動方向から `dirFromGridVector` で8方向、HP バー、状態異常の色（凍結＝青白い、燃焼＝赤橙、毒＝緑、結晶＝紫の光）、heat 段階の見た目（段階1 薄い赤、2 赤く光る、3 炎のオーラ）。
  - 壁：ひび（crack 1〜3）、溶けている間の揺れ。
  - タワー：攻撃方向に向く（8方向）、射程円（選択時・設置プレビュー時のみ。アイソメなので楕円）。
- `src/game/scenes/HudScene.ts`（戦闘画面に重ねる UI 専用シーン。カメラのズームの影響を受けない）：
  - 霊氷・ライフ・ウェーブ（n/10）・保留玉（4個の枠。中身はタスク10/11）・速度（1x/2x/3x）・一時停止・次ウェーブ予告（敵アイコンと数）・前倒しボタン。
  - タワーボタン（解放済みのみ。費用。足りないときは灰色）。壁ボタン。
  - 選択中のタワー/壁の情報パネル：レベル、特化スロット（中身はタスク07）、強化・売却・取消・狙いの切り替え。
  - ボタンはすべてマウスでもキー（GDD §3.3 の表）でも操作できる。
- 入力（GDD §3.3 の表を **全部**）：壁モード、タワー選択、選択解除、既存オブジェクトの選択、売却、一時停止、速度、前倒し、壁のドラッグ連続設置。
- 配置プレビュー（GDD §3.3）：カーソル位置に置いた場合の予定経路を光る線で表示（`previewPlacement`）。完全封鎖になるなら赤線＋「熱で溶かされます」。タワーで塞ぐ配置は×印で不可表示。
- カメラ：ホイールでズーム（0.5〜1.5）、右ドラッグ or 中ドラッグでパン。

## 受け入れ条件
1. ステージ1をマウスだけで最初から最後まで遊べる（勝ちも負けも）。
2. キーボードショートカットが全部効く。
3. 経路プレビューが壁を置くたびに正しく変わる。
4. 1x/2x/3x で敵の速さが変わり、一時停止で止まる。
5. ブラウザのコンソールにエラーが出ない。
6. HUD はズームしても大きさが変わらない。
