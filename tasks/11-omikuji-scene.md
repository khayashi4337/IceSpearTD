# 11 おみくじの演出画面（パチンコの大当たり演出）

GDD §6.4（演出の段階7つの全部）、§6.5、§2.2（ユキネ・フミヤ・セツナ）

## 作るもの
- `src/game/scenes/OmikujiScene.ts`：戦闘画面の上に重ねるシーン。ウェーブ間に保留があれば「おみくじを引く」ボタンが光る。
- 演出（タスク10の `Presentation` の結果に従って再生する。演出側で結果を変えない）：
  1. 保留変化予告：HUD の保留玉が白→青→緑→赤→金→虹に変化（変化の瞬間に光と音）。
  2. ステップアップ予告：雪の結晶が舞い、STEP1〜5 の表示が段階的に大きく派手に。
  3. 群予告：雪うさぎの群れが画面を横切る（プレースホルダー可。素材ID `fx_snow_rabbit`）。
  4. リーチ：おみくじ筒が揺れ、「吉」と「大吉」の札が交互に見える。背景が暗転、集中線。
  5. 擬似連：止まりかけて「再始動」（1〜3回）。回数ごとに色が変わる。
  6. カットイン：ユキネ（通常）/ フミヤ（金枠・激アツ）/ セツナ（虹・確定）。画像は `cutin_yukine`, `cutin_fumiya`, `cutin_setsuna`（素材が無い間は名前入りのシルエット）。
  7. 当否：大吉（画面が凍る → ひび → 砕けて虹色の光と大量の花火・専用ファンファーレ）、吉（金の札・紙吹雪）、中吉〜末吉（札が開く）、凶（画面が一瞬赤く熱を帯び、ユキネが「…でも、次は来ますよ！」）。
- 札選び：候補のカードを並べ、選べる数だけ選ぶ（カードにタグ・レア度・効果・「今の編成でのタグ数の変化（例：凍結 3→4 ★段階ボーナス到達！）」を表示）。組み合わせが完成する札は光らせる。
- 演出の長さ（§6.5）：フル / 激アツのみフル / 倍速。クリックでスキップ（大吉の当否の瞬間は 0.5 秒待つ）。
- 天井到達の専用演出。

## 受け入れ条件
1. デバッグ用 `?debug=omikuji` で、結果と演出の組み合わせを指定して再生できる（全組み合わせを目で確認できる）。
2. 大吉の演出が最大 12 秒以内。スキップが効く。
3. 札選びで「段階ボーナス到達」の表示が正しい。
4. 演出中に戦闘は進まない。
