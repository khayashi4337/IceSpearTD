# 8. ゲーム世界観：氷結の大陸アイスガルド

遥か昔、氷結の大陸アイスガルドは、氷の女王の統治下で平和な時代を謳歌していました。しかし、ある日突然、未知の力「熱の侵食」が大陸を襲い、氷の女王は深い眠りにつきました。熱の侵食は徐々に大陸を蝕み、氷の秩序が乱れ始めています。

### プレイヤーの立場

プレイヤーは、氷の守護者の末裔である若者として物語を始めます。しかし、その力はまだ眠ったままで、ごく基本的な氷の魔法しか使えません。

### ゲーム構造

1. **メインストーリー**
   - 大陸各地に散らばる「氷の聖域」を守り、力を取り戻すことが目標です。
   - 各聖域では複数のWaveからなる熱の侵食との戦いが待っています。
   - 聖域を守るたびに、眠れる女王の力の一部を受け取り、新たなスキルを習得します。

2. **サイドクエスト**
   - メインストーリーと並行して、様々なサイドクエストが発生します。
   - これらは任意ですが、追加のスキルポイントや特殊アイテムを獲得できる機会となります。

3. **マップ選択の自由度**
   - プレイヤーは大陸地図から自由に次の目的地を選べます。
   - 各地域には推奨レベルがありますが、挑戦する順番は自由です。

4. **周回要素**
   - 各聖域には「熱の侵食レベル」があり、クリアするたびに上昇します。
   - レベルが上がると敵が強くなりますが、報酬も増加します。
   - これにより、同じマップを何度も挑戦する動機が生まれます。

### ストーリー展開

1. **覚醒（チュートリアル）**
   - 故郷の村が熱の侵食に襲われ、プレイヤーの力が目覚めます。
   - 基本的なタワーディフェンスの仕組みを学びます。

2. **旅立ち**
   - 氷の女王の眠る「永劫の氷城」へ向かうよう導かれます。
   - 途中、各地の聖域を守ることで女王を目覚めさせる力を得られると知ります。

3. **試練の数々**
   - 大陸各地の聖域を巡り、熱の侵食と戦います。
   - 各聖域クリア後、新たなスキルを習得します。
   - 例：「氷の矢」、「フロストノヴァ」、「絶対零度の鎧」など。

4. **真実の発見**
   - 旅を進めるうちに、熱の侵食の正体が「太古の炎龍」の目覚めによるものだと判明します。
   - 炎龍は大陸の気候バランスを保つために必要な存在でしたが、長い氷の時代により暴走してしまったのです。

5. **選択の時**
   - プレイヤーは最終的に二つの選択肢を突きつけられます：
     a) 氷の女王を目覚めさせ、炎龍を再び封印する
     b) 炎龍と対話し、新たな気候バランスを築く

6. **結末**
   - 選択によって異なる最終決戦が待っています。
   - どちらを選んでも、大陸の秩序は回復しますが、その後の世界の様子が変わります。

### スキルシステムとの連携

- 各聖域で特定のWaveをクリアするたびに、スキルポイントを獲得します。
- 獲得したポイントで、氷の魔法ツリーからスキルを習得できます。
- スキルは戦闘中の特殊能力だけでなく、タワーの強化やリソース管理の改善にも使えます。

### 周回プレイの動機

- 選択肢による複数のエンディング
- 聖域の熱の侵食レベル上昇による難易度と報酬の増加
- 未取得のスキルの習得
- 隠しエンディングの示唆（全聖域を最高レベルでクリアした場合のみ）
