# 3. ゲームプレイの要素

### マップとタワーの配置

| マップ名       | 特徴                                           |
| -------------- | ---------------------------------------------- |
| 凍てつく森     | 複雑な氷の迷路、遠回りを強いる凍結した地形     |
| 氷河の谷       | 巨大な氷塊による障害物、狭い通路               |
| 氷の洞窟       | 滑りやすい氷の床、移動速度が低下する箇所       |
| 雪原のオアシス | 広大な雪原、一部の敵は雪に潜んで隠れる         |

### タワーの種類と特性

| タワー名     | 攻撃タイプ   | 特性                                                           |
| ------------ | ------------ | -------------------------------------------------------------- |
| 氷槍の塔     | 範囲攻撃     | 広範囲の敵を凍結させ、移動速度を大幅に低下させる。             |
| 氷晶の塔     | 単体追尾攻撃 | 鋭い氷の結晶を発射し、敵を徐々に結晶化させる。                 |
| 氷河の塔     | 即死攻撃     | 巨大な氷塊を投げつけ、特定の条件下で敵を即座に撃破する。       |
| 吹雪の塔     | 範囲魔法攻撃 | 冷たい風と雪を吹き付け、空中の敵に対して有効な攻撃を行う。     |

### タワーのアップグレード

| タワー名   | アップグレードの種類                   | 効果                                                                         |
| ---------- | -------------------------------------- | ---------------------------------------------------------------------------- |
| 氷槍の塔   | 氷の強化、範囲拡大、凍結時間の延長     | 攻撃範囲が広がり、凍結効果の持続時間が延長される。                           |
| 氷晶の塔   | 結晶化促進、追尾性能向上、多重結晶生成 | 結晶化速度が上昇し、より多くの敵を同時に狙える。結晶の多重生成が可能になる。 |
| 氷河の塔   | 即死確率アップ、氷塊サイズ拡大         | 即死攻撃の成功率が増加し、投げつける氷塊のサイズと攻撃範囲が広がる。         |
| 吹雪の塔   | 暴風域拡大、吹き飛ばし効果の増強       | 吹雪の範囲が大きくなり、吹き飛ばし効果が増強され、より多くの敵を制御できる。 |

### バリケードシステム

| バリケード種類 | 耐久度 | 設置コスト | 特殊効果                         |
| -------------- | ------ | ---------- | -------------------------------- |
| 氷の壁         | 100    | 50         | 敵の移動速度を10%低下させる      |
| 厚氷の障壁     | 200    | 100        | 敵の移動速度を25%低下させる      |
| 魔法氷晶       | 150    | 150        | 敵に継続的な凍結ダメージを与える |

### タワー管理システム

- タワーの設置取り消し：建設後15秒以内なら80%のコストを返金
- タワーの売却：建設コストの50%を回収
- タワーのアップグレード：各レベルごとに固定コストで性能向上

| 氷槍の塔   | レベル3  | 凍結効果の持続時間が大幅に延長           | 300    |
| 氷晶の塔   | レベル2  | 攻撃力が増加、氷の結晶化速度が上昇       | 250    |
| 氷晶の塔   | レベル3  | 敵を氷の彫像に変える能力を獲得           | 350    |
| 氷河の塔   | レベル2  | 耐久度が増加、即死確率が上昇             | 220    |
| 氷河の塔   | レベル3  | 周囲のタワーに氷の防御膜を付与           | 330    |
| 吹雪の塔   | レベル2  | 攻撃範囲が拡大、吹き飛ばし効果上昇       | 280    |
| 吹雪の塔   | レベル3  | 暴風雪を起こし、広範囲に持続ダメージ     | 400    |
